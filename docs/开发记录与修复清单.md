### 2.6 文件编码

仓库中 **23 个 `.cs` 文件使用 GBK（代码页 936）编码且无 BOM**，其余为 UTF-8。
在非中文 ANSI 代码页的机器（或 CI）上，Roslyn 会按系统默认代码页解码，
导致中文注释与**中文字符串字面量全部乱码**，甚至编译失败。

已将这 23 个文件统一转换为 **UTF-8 with BOM**（BOM 保证任何环境下都能被正确识别）：

Assets/Scripts/Inventory&Shop/Shop/ShopButtonToggles.cs

## 五、技术债与后续计划

以下问题**已定位但需要策划或美术决策**，因此未擅自改动数据：

1. **技能树 24 个节点全部指向同一个技能。**
   `UIManager.prefab` 中每个 `SkillSlot` 的 `skillSO` 都指向 `MaxHealthBoost`
   （`guid: 933ee6064db58a04c91d794864610904`），而 `MaxAttackBoost` 与 `MaxSpeedBoost`
   **没有被任何场景或预制体引用**。代码侧已补齐三个技能的效果实现，
   只需在编辑器中把部分节点的 `skillSO` 换成攻击 / 速度技能即可生效。

2. **属性面板有 7 项是写死的占位数据。**
   `StatsUI` 中「攻速」「暴击率」「暴击伤害」「防御」「闪避率」「法力值」「格挡率」
   都直接输出常量 `1`，对应属性在 `StatsManager` 中并不存在。
   建议要么实现这些属性，要么从 UI 中移除对应槽位。

3. **开发期测试资源混在生产资源里。**
   例如 `QuestLikeTheVideo` / `QuestLikeTheVideo 1` / `QuestLikeTheVideo 2`、`QuestTest`、
   `TestQuest`、`NoAvailableQuest`、内容完全相同的 `PoemD` 与 `PoemD 1`。
   建议移入独立的 `_Dev` 目录或直接删除。
